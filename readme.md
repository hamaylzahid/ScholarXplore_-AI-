<div align="center">
<h2>Project Overview</h2>
</div>

ScholarXplore AI is a next-generation platform built to automate the discovery of global scholarships and convert raw data into actionable intelligence.

Instead of manually searching across fragmented sources, the system:

- Scrapes scholarship data from the web  
- Processes and structures it intelligently  
- Presents it through an interactive Streamlit interface  
- Generates analytics that reveal real-world trends  

This project is not just a scraper. It is a decision-support system for students aiming for international opportunities.

<br><hr><br>

<div align="center">
<h2>Key Features</h2>
</div>

- Automated scholarship discovery via web scraping  
- Clean and structured data pipeline  
- FastAPI-powered backend for high performance  
- Streamlit-based interactive UI  
- Real-time analytics and insights  
- Modular and scalable architecture  

<br><hr><br>

<div align="center">
<h2>System Architecture</h2>
</div>

The system is designed as a layered pipeline:

1. Data Collection  
   - Web scraping using BeautifulSoup / Selenium  

2. Data Processing  
   - Cleaning, filtering, structuring  

3. Core Logic  
   - Scholarship classification and aggregation  

4. Backend Layer  
   - FastAPI handles processing and endpoints  

5. Frontend Layer  
   - Streamlit provides interactive visualization

<h2>Installation</h2>
</div>

<pre>
git clone https://github.com/hamaylzahid/ScholarXplore_-AI-.git
cd ScholarXplore_-AI-
</pre>

Create virtual environment:

<pre>
python -m venv venv
venv\Scripts\activate
</pre>

Install dependencies:

<pre>
pip install -r requirements.txt
</pre>

<br><hr><br>

<div align="center">
<h2>Usage</h2>
</div>

Run FastAPI backend:

<pre>
uvicorn api:app --reload
</pre>

Run Streamlit UI:

<pre>
streamlit run app.py
</pre>

Access UI:

<pre>
http://localhost:8501
</pre>
